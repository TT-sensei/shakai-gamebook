# 社会科ゲームブック

「読む → 考える → 選ぶ → 結果を見る」を軸にした、5年生社会科を主な対象とする学習ゲームブックです。

現在は「米づくり」「自動車づくり」「ニュースづくり」を収録しています。

## 対象・ねらい

主な対象は小学校5年生の社会科です。

社会の仕組みや人々の働きを、知識として覚えるだけでなく、「なぜそうするのか」「どのようにつながっているのか」「別の選択をしたらどうなるか」を、場面の中で考えながら学ぶことをねらいとしています。

ゲームの中心は、クイズの正解を当てることではありません。資料や状況を読み、必要な情報を整理し、判断し、その結果を見て次の判断につなげる体験を重視しています。

## 収録ゲーム

### 米づくり

米づくりを取り巻く自然条件、農家の工夫、地域とのつながりなどを、季節や作業の流れに沿って体験します。

### 自動車づくり

自動車ができるまでを、企画から出荷までの工程として体験します。

基本の流れは、

「企画 → プレス → 溶接 → 塗装 → 組立 → 検査 → 出荷」

です。

ゲーム中は現在の工程を確認でき、終わった工程、このあと行う工程、各工程の主な仕事を振り返れます。

主な学習内容は、企画と使う人・社会の変化、多くの会社による分業と協力、プレス・溶接・塗装・組立などの工程、人と機械の役割分担、品質管理、異常時の対応、環境への配慮、生産効率、最終検査、輸送、国内外の市場とのつながりなどです。

突発イベントでは、部品の到着遅れ、工程の異常、現場からの改善案、環境への工夫、ほかのメーカーとの競争などを扱います。「速くつくること」だけでなく、品質・安全・環境などとの関係を考える場面として設計しています。

### ニュースづくり

ニュースができるまでの流れを、「情報を集める → 編集会議 → 取材 → 確認 → 選ぶ → 原稿・編集 → 放送」という一連のプロセスとして体験します。

仕事の名前を覚えることを中心にするのではなく、ニュースをつくるために、

- 情報をどこから集めるか
- 何をニュースとして扱うか
- 取材で何を確かめるか
- 「らしい」という情報をそのまま使わず、根拠を確認すること
- 必要な情報を選び、順序を考えること
- 事実を正確に、短く、分かりやすく伝えること
- 放送直前に新しい情報が入ったときにも確認して対応すること

を体験できる構成にしています。

ニュースづくりでは「正確さ」「根拠」「伝わりやすさ」「速さ」「配慮」を状態として表示し、判断によって変化します。確認されていない情報や不適切な伝え方が重なると信頼を失い、番組終了となるゲームオーバーも設定しています。

## ゲーム体験の基本設計

社会科の知識を単発のクイズとして問うのではなく、社会の中で起こる状況を読み、自分で判断し、その選択によって何が変わるかを体験します。

基本の流れは、

「状況を読む → 考える → 選ぶ → 結果を見る → 次の判断へ」

です。

各ゲームには、単元で必ず扱う「核となる学習内容」と、プレイごとに変化する「突発イベント」を設定しています。

突発イベントによって毎回まったく同じ展開になることを避け、同じ単元を複数回プレイしても、異なる判断場面に出会えるようにしています。一方で、必須の学習内容が偶然のイベントによって抜け落ちないようにしています。

また、工程や学習の流れの途中に「次は何をする？」という確認場面を入れ、社会の仕事や仕組みを順番として理解できるようにしています。

基本的には教室で20〜25分程度の1プレイを想定しています。授業での導入・展開・振り返りのほか、家庭での復習や、同じ単元をもう一度試す活動にも使える構成です。

## UI・設計原則

- GitHub Pagesで動作する静的HTML/CSS/JavaScript
- APIキー・バックエンド不要
- シナリオとゲームエンジンを分離
- edu-kitのタブレットファースト、読みやすさ、共通UIの考え方を活用
- タブレットでの操作を最優先し、問題文・選択肢・結果を見やすくする
- 装飾やゲーム要素が学習を邪魔しない
- 「正解・不正解」だけで終わらず、選択による結果と振り返りを重視
- 状態の変化によって判断の結果を見える化
- 突発イベントによって同じ単元を複数回体験できる
- 必須学習内容は突発イベントによって省略しない
- 単元固有の教育内容はデータ側に置き、エンジン側に書き込まない
- 1プレイ20〜25分程度を基本とする
- 学習用端末で扱いやすい大きなタップ領域と読みやすい文字サイズを基本とする

## 開発方針

このゲームブックは、ゲームとしての楽しさと社会科の学習内容が分離しないことを重視します。

「たまたま正解した」ではなく、「状況を読んで考えたから結果が変わった」と感じられる体験を目指します。

ゲーム要素は学習内容を分かりやすくするために使い、勝敗や演出だけを目的にしません。プレイ後に「なぜその判断をしたのか」「別の選択ならどうなったか」を話したり、ノートに整理したりできる余白も残します。
